SHOH PIZZA — РЕАЛИСТИЧНЫЙ ЛОКАЛЬНЫЙ САЙТ / 5 УРОК AUTHENTICATION

Новое: удалена отдельная страница Authentication Lab. Уязвимости находятся в настоящих функциях сайта: вход, MFA, сессия, восстановление пароля. Главная страница, меню, корзина, заказы и панель менеджера выглядят как нормальный сайт пиццерии.

ТРЕБОВАНИЯ: Python 3 (без pip и npm).
ЗАПУСК: python3 app.py --reset
ОТКРЫТЬ: http://127.0.0.1:8770
Проверка проекта: python3 verify_site.py
ЗАЩИЩЁННОЕ СРАВНЕНИЕ: остановить сервер и запустить python3 app.py --secure (или --secure --port 8771).

Вымышленные аккаунты:
student@shohpizza.test / Pizza2026! / 246810
manager@shohpizza.test / Manager2026! / 864200

ЛОКАЛЬНЫЕ ОШИБКИ (VULNERABLE MODE):
- Login говорит отдельно «email не найден» и «неверный пароль» (enumeration).
- Login не имеет rate limit (в --secure 429).
- После пароля, но до MFA, ошибочно выдаётся доступ к СВОИМ заказам, без доступа к manager (MFA design flaw).
- Logout не аннулирует сессию на сервере (session revocation flaw).
- Password reset раскрывает наличие email и допускает повторное использование тестовой ссылки (в --secure исправлено).

ОТЛИЧИЯ ОТ РЕАЛЬНОГО САЙТА: сервер только localhost, все клиенты/пиццы/заказы выдуманы, нет оплаты, платёжных провайдеров и внешнего SMTP. Пароли хэшируются. Отдельная функция manager по-прежнему защищена.

ВАЖНО: этот сайт НЕЛЬЗЯ выкладывать в Интернет, запускать с хостом 0.0.0.0 или использовать для настоящих пользователей. Использовать только для обучения на своей машине.
